# n8n 节点执行环境深度技术分析

> **技术专题** - 全面解析 n8n 节点的执行机制、安全模型、并发控制和第三方库管理

本专题基于 n8n 源码深度分析，全面解构节点执行环境的技术架构，为开发者提供完整的技术参考和实践指导。

---

## 🎯 专题概览

### 核心发现
- **双重执行架构**: 传统 vm2 沙箱 + 新一代 Task Runner 架构
- **多层安全防护**: 15+ 种不同的安全机制组合  
- **智能化优化**: 基于 AST 静态分析的性能优化
- **灵活部署模式**: 内部/外部模式适应不同安全需求

### 适用对象
- **n8n 节点开发者**: 理解执行环境和开发约束
- **系统架构师**: 了解安全模型和部署选项
- **运维工程师**: 掌握性能调优和监控配置
- **安全专家**: 评估沙箱机制和安全策略
