# 01 - 环境要求和初始设置

本文档详细介绍 n8n 本地开发环境的要求和初始设置步骤，确保您能够顺利启动本地开发环境。

---

## 1. 系统要求概览

### 1.1 硬件要求

n8n 是一个资源密集型的 monorepo 项目，建议的最低配置：

```
CPU:     4 核心以上
内存:    8GB RAM（推荐 16GB+）
存储:    20GB 可用空间
网络:    稳定的互联网连接
```

### 1.2 操作系统支持

```
✅ macOS 10.15+
✅ Ubuntu 18.04+  
✅ Windows 10+ (推荐使用 WSL2)
✅ CentOS 7+
✅ Debian 9+
```

---

## 2. Node.js 环境配置

### 2.1 Node.js 版本要求

n8n 对 Node.js 版本有严格要求：

```bash
# 必需版本
Node.js: >= 22.16 (最新 LTS 推荐)
支持版本: 22.16 <= version <= 24.x
```

### 2.2 Node.js 安装方法

#### 方法 1: 使用 Node Version Manager (推荐)

**macOS/Linux:**
```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# 重新加载 shell 配置
source ~/.bashrc  # 或 ~/.zshrc

# 安装并使用 Node.js 22
nvm install 22
nvm use 22
nvm alias default 22

# 验证版本
node --version  # 应该显示 v22.x.x
```

**Windows (使用 nvm-windows):**
```powershell
# 下载并安装 nvm-windows
# https://github.com/coreybutler/nvm-windows/releases

# 安装 Node.js
nvm install 22.16.0
nvm use 22.16.0

# 验证版本
node --version
```

#### 方法 2: 直接安装

**macOS (使用 Homebrew):**
```bash
# 更新 Homebrew
brew update

# 安装 Node.js
brew install node@22

# 链接到系统路径
brew link node@22 --force

# 验证版本
node --version
```

**Ubuntu/Debian:**
```bash
# 添加 NodeSource repository
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -

# 安装 Node.js
sudo apt-get install -y nodejs

# 验证版本
node --version
npm --version
```

### 2.3 npm 更新（可选）

```bash
# 更新 npm 到最新版本
npm install -g npm@latest

# 验证版本
npm --version
```

## 3. Corepack 配置

### 3.1 什么是 Corepack

Corepack 是 Node.js 内置的包管理器管理工具，可以自动管理 pnpm、yarn 等包管理器的版本。

### 3.2 启用 Corepack

**标准安装的 Node.js:**
```bash
# 启用 corepack
corepack enable

# 验证 corepack 是否可用
corepack --version
```

**macOS 使用 Homebrew 安装的 Node.js:**
```bash
# Homebrew 移除了 corepack，需要单独安装
brew install corepack

# 启用 corepack
corepack enable

# 验证
corepack --version
```

**Windows:**
```powershell
# 以管理员身份运行 PowerShell
# 启用 corepack
corepack enable

# 验证
corepack --version
```

### 3.3 配置 pnpm

```bash
# 激活项目指定的 pnpm 版本
corepack prepare --activate

# 验证 pnpm 版本（应该是 10.12.1 或更高）
pnpm --version
```

## 4. 构建工具安装

n8n 的依赖项需要原生编译，因此需要安装相应的构建工具。

### 4.1 macOS

```bash
# 安装 Xcode Command Line Tools
xcode-select --install

# 或者安装完整的 Xcode (从 App Store)
# 验证安装
gcc --version
make --version
```

### 4.2 Ubuntu/Debian

```bash
# 安装构建必需的包
sudo apt-get update
sudo apt-get install -y build-essential python3

# 验证安装
gcc --version
make --version
python3 --version
```

### 4.3 CentOS/RHEL

```bash
# 安装开发工具组
sudo yum groupinstall "Development Tools"
sudo yum install python3

# 或者在较新版本上使用 dnf
sudo dnf groupinstall "Development Tools"  
sudo dnf install python3

# 验证安装
gcc --version
make --version
python3 --version
```

### 4.4 Windows

```powershell
# 方法 1: 使用 Windows Build Tools (推荐)
npm install -g windows-build-tools

# 方法 2: 安装 Visual Studio Build Tools
# 下载并安装: https://visualstudio.microsoft.com/visual-cpp-build-tools/
# 确保选择 "C++ build tools" 工作负载

# 方法 3: 使用 chocolatey
choco install visualstudio2019buildtools
choco install visualstudio2019-workload-vctools
```

## 5. 项目获取和初始设置

### 5.1 Fork 和 Clone 项目

```bash
# 1. Fork n8n 仓库 (在 GitHub 网页上操作)
# https://github.com/n8n-io/n8n

# 2. Clone 你的 fork
git clone https://github.com/<your_github_username>/n8n.git

# 3. 进入项目目录
cd n8n

# 4. 添加上游仓库
git remote add upstream https://github.com/n8n-io/n8n.git

# 5. 验证远程仓库配置
git remote -v
```

### 5.2 安装依赖

```bash
# 安装所有依赖包 (这可能需要 5-15 分钟)
pnpm install

# 如果遇到网络问题，可以使用镜像
pnpm config set registry https://registry.npmmirror.com/
pnpm install
```

### 5.3 构建项目

```bash
# 构建所有包 (首次构建可能需要 10-20 分钟)
pnpm build

# 构建特定组件
pnpm build:backend   # 仅构建后端
pnpm build:frontend  # 仅构建前端
pnpm build:nodes     # 仅构建节点包
```

## 6. 环境验证

### 6.1 验证依赖版本

```bash
# 检查关键版本
node --version     # 应该是 >= 22.16
pnpm --version     # 应该是 >= 10.2.1
git --version      # 任何现代版本

# 检查 corepack
corepack --version

# 检查构建工具
gcc --version      # Linux/macOS
make --version     # Linux/macOS
python3 --version # 所有平台
```

### 6.2 验证项目结构

```bash
# 检查关键目录
ls -la
# 应该看到:
# - packages/          (所有包的源码)
# - docs/             (文档)
# - package.json      (根配置)
# - turbo.json        (构建配置)
# - pnpm-lock.yaml    (锁定文件)

# 检查包结构
ls packages/
# 应该看到:
# - cli/              (CLI 包)
# - core/             (核心包) 
# - editor-ui/        (前端编辑器)
# - nodes-base/       (基础节点)
# - workflow/         (工作流包)
```

### 6.3 快速测试启动

```bash
# 快速验证是否可以启动
pnpm start

# 如果看到类似输出，说明设置成功:
# n8n ready on 0.0.0.0, port 5678
# Version: 1.103.0
# Editor is now accessible via:
# http://localhost:5678

# 按 Ctrl+C 停止服务器
```

## 7. 环境配置建议

### 7.1 Git 配置

```bash
# 配置 Git 用户信息
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

# 配置 Git 编辑器 (可选)
git config --global core.editor "code --wait"  # 使用 VS Code

# 配置自动换行处理
git config --global core.autocrlf input   # macOS/Linux
git config --global core.autocrlf true    # Windows
```

### 7.2 IDE 配置建议

**VS Code (推荐):**
```bash
# 安装 VS Code
# https://code.visualstudio.com/

# 项目已包含推荐的 VS Code 配置:
# - .vscode/settings.json
# - .vscode/launch.json (调试配置)
# - .vscode/extensions.json (推荐扩展)

# 打开项目
code .
```

### 7.3 Shell 别名设置 (可选)

```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
alias n8n-dev="cd /path/to/n8n && pnpm dev"
alias n8n-build="cd /path/to/n8n && pnpm build"
alias n8n-test="cd /path/to/n8n && pnpm test"

# 重新加载配置
source ~/.bashrc  # 或 ~/.zshrc
```

## 8. 常见安装问题

### 8.1 Node.js 版本问题

```bash
# 问题: Node.js 版本不兼容
# 解决: 使用 nvm 管理版本

nvm install 22
nvm use 22
nvm alias default 22
```

### 8.2 pnpm 安装失败

```bash
# 问题: pnpm 不可用或版本过旧
# 解决: 重新配置 corepack

corepack disable
corepack enable
corepack prepare --activate
```

### 8.3 依赖安装失败

```bash
# 问题: 网络问题或构建失败
# 解决: 清理缓存重试

pnpm store prune
rm -rf node_modules
rm -rf packages/*/node_modules
pnpm install
```

### 8.4 构建工具问题

**macOS:**
```bash
# 重新安装 Xcode Command Line Tools
sudo xcode-select --reset
xcode-select --install
```

**Linux:**
```bash
# 重新安装构建工具
sudo apt-get remove build-essential
sudo apt-get install build-essential python3
```

**Windows:**
```powershell
# 清理并重新安装
npm uninstall -g windows-build-tools
npm install -g windows-build-tools
```

### 8.5 权限问题

**macOS/Linux:**
```bash
# 修复 npm 全局包权限
sudo chown -R $(whoami) $(npm config get prefix)/{lib/node_modules,bin,share}
```

**Windows:**
```powershell
# 以管理员身份运行命令
# 或者使用 nvm-windows 管理 Node.js
```
