# 00 - n8n 项目概览

本文档旨在提供 n8n 项目的顶层视图，结合其公开信息（如 README）和代码层面的架构分析，形成一个全面的项目介绍。

## 1. 项目定位与核心价值

n8n (发音为 `n-eight-n`，是 "nodemation" 的缩写) 是一个**面向技术团队的、可扩展的、源码可见的工作流自动化平台**。

与市面上的其他自动化工具（如 Zapier, Make）相比，n8n 的核心价值主张在于**灵活性**和**控制权**：

- **代码的灵活性**: 它不仅仅是一个“无代码”或“低代码”工具。它在提供可视化编辑器的同时，允许开发者在任何需要的地方无缝嵌入和执行自定义的 JavaScript 或 Python 代码，甚至引入 npm 包。这使得它能处理更复杂的逻辑。
- **数据的控制权**: 通过其 "fair-code" 许可模式，n8n 允许用户自由地进行**自托管（Self-Host）**。这意味着用户可以将 n8n 部署在自己的服务器、私有云甚至隔离网络中，确保所有敏感数据（如凭证、工作流执行日志）都保留在自己的基础设施内，从而满足严格的数据安全和合规要求。

## 2. 目标用户

n8n 的主要目标用户是**技术人员**，包括但不��于：

- **软件开发者**: 需要将不同系统的 API 进行粘合，构建内部工具（Internal Tools），或实现复杂的 CI/CD 流程。
- **DevOps / SRE 工程师**: 需要自动化基础设施的监控、告警和运维任务。
- **技术型产品经理或运营**: 具备一定的脚本编写能力，需要构建复杂的自动化业务流程。

## 3. 核心功能

- **可视化工作流编辑器**: 提供一个基于节点（Node）和连接（Connection）的拖拽式画布，直观地构建自动化流程。
- **丰富的节点库**: 提供超过400个开箱即用的节点，用于集成各种常见的 SaaS 服务、数据库和通用工具（如 HTTP 请求、数据处理等）。
- **AI 原生能力**: 内置与 LangChain 等 AI 框架的集成，允许用户构建和运行自己的 AI 代理（Agent）和多步骤的 AI 工作流。
- **灵活的触发器**: 支持多种方式触发工作流，包括 Webhook、定时任务（Cron）、手动执行，以及来自第三方应用（如 Stripe, GitHub）的事件。
- **企业级特性**: 提供用户管理、单点登录（SSO）、高级权限控制等功能，满足企业级部署的需求。

## 4. 技术栈与架构概览

n8n 是一个基于 **Node.js** 和 **TypeScript** 的 Monorepo 项目，其前后端分离。

- **前端**:
    - **框架**: **Vue.js 3**
    - **构建工具**: **Vite**
    - **UI 库**: **Element Plus**
    - **状态管理**: **Pinia**
    - **核心**: `n8n-editor-ui` 包，一个功能丰富的单页应用（SPA），提供了可视化的工作流编辑器。

- **后端**:
    - **运行时**: **Node.js**
    - **Web 框架**: **Express.js**
    - **核心**:
        - `packages/cli`: 应用的启动器，整合所有模块并提供 Web 服务。
        - `packages/core`: 无状态的工作流执行引擎，负责调度和运行工作流。
        - `packages/workflow`: 定义了工作流的数据模型和类型。
        - `packages/nodes-base`: 包含了所有内置节点和凭证的实现。
    - **数据库**: 支持 **SQLite, PostgreSQL, MySQL/MariaDB**，用于持久化存储工作流、凭证和执行日志。

- **项目管理**:
    - **包管理器**: **pnpm**
    - **Monorepo 工具**: **Turbo**

这种架构将界面、核心逻辑、数据模型和功能扩展清晰地分离开来，使得项目易于维护和扩展。详细的模块分析请参见 `01_Architecture_And_Packages.md`。
