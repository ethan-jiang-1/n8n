## 🔍 研究方法论

### 📊 数据来源
- **代码分析**: 基于 n8n 1.103.0 版本的源代码
- **结构分析**: 通过 `packages/nodes-base/` 和 `@n8n/n8n-nodes-langchain` 包
- **配置解析**: package.json、TypeScript 定义文件
- **UI 分析**: 前端分类展示逻辑和用户界面

### 🛠️ 分析工具
- **目录遍历**: 自动化统计节点数量和分布
- **源码解析**: TypeScript AST 分析节点定义
- **配置分析**: JSON/YAML 配置文件解析
- **可视化**: Mermaid 图表和数据表格

### ✅ 准确性保证
- **版本锁定**: 基于特定版本的精确分析
- **交叉验证**: 多个数据源相互验证
- **持续更新**: 跟踪项目发展及时更新数据

## 🎯 核心发现预览

> 以下是研究的主要发现，详细内容请查看具体文档

### 📊 规模概览
- **总节点数量**: 400+ 个内置节点
- **主要分类**: 15+ 个核心分类
- **AI 节点**: 50+ 个 LangChain 集成节点
- **覆盖领域**: 通信、数据处理、AI、云服务、开发工具等

### 🏆 核心优势
- **生态完整性**: 覆盖企业应用的主要场景
- **AI 原生**: 深度集成 LangChain 和各种 AI 模型
- **扩展性**: 支持自定义节点和社区贡献
- **易用性**: 可视化编排降低技术门槛

### 🎨 独特价值
- **代码与可视化并重**: 支持嵌入自定义代码
- **企业级特性**: 权限控制、审计、版本管理
- **自托管友好**: 完全的数据控制权
- **活跃生态**: 持续的功能更新和社区贡献
